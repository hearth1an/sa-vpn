# SA VPN

Свой VPN одной командой. Домен покупать не нужно.

## Как установить

1. Купите чистый VPS с Ubuntu 22.04 или 24.04 и публичным IPv4. В панели провайдера откройте TCP-порты **80, 443 и 2096**.
2. Войдите на сервер по SSH под пользователем **root**.
3. Скопируйте и запустите команду:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/hearth1an/sa-vpn/main/install.sh | bash
   ```

4. Дождитесь установки. В конце введите, сколько ключей нужно: **от 1 до 5**. Скрипт покажет ключи, ссылки подписок и QR-коды с названиями **1, 2, 3…**
5. В **Happ** или **Incy** добавьте полученную ссылку подписки либо импортируйте VLESS-ключ. Включите VPN и пользуйтесь.

На новом VPS повторите эти же шаги — получите новые ключи. Повторный запуск на уже установленном сервере покажет прежние.

Для установки по этой команде репозиторий должен быть публичным.
